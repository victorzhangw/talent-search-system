基本資訊

URL 結構

前綴說明
/api/v2/主要業務 API（候選人、聊天、初始化、模組）
/auth/JWT 認證端點
/chat/聊天串流與歷史紀錄
/api/admin/後台管理端點（獨立 JWT 認證）
/health健康檢查（無認證）

統一回應信封（Unified Response Envelope）

Content-Type： 所有 JSON 回應使用 application/json；聊天串流端點使用 text/event-stream（SSE）。

除 /health 與 SSE 串流外，所有端點統一使用以下信封格式：

成功回應（success: true）
{
  "success": true,
  "data":    <payload>,     // 實際業務資料，型別依端點而異
  "error":   null,
  "meta":    null            // 選填：分頁、skipped_count 等附加資訊
}
錯誤回應（success: false）
{
  "success": false,
  "data":    null,
  "error":   {
    "code":    "ERROR_CODE",     // 機器可讀代碼，見下方錯誤代碼表
    "message": "人類可讀描述",
    "details": <any>,           // 選填：詳細資訊
    "field":   "field_name"      // 選填：驗證失敗的欄位名稱
  },
  "meta":    null
}
CORS： 後端全域開啟 CORS，UAT 環境允許所有 Origin。正式環境需限縮。

認證流程

系統採用兩套獨立 JWT 認證機制：

1. Plugin JWT（一般使用者）

從 POST /auth/login 取得 token，放入 Authorization: Bearer <token> Header 呼叫所有 /api/v2/* 及 /chat/* 端點。Token 有效期 15 分鐘，Audience: traitty，Scope: traitty_plugin。

2. Admin JWT（後台管理者）

從 POST /api/admin/login 取得 access_token，放入 Authorization: Bearer <token> Header 呼叫所有 /api/admin/* 端點（login 除外）。

Header 範例

HTTP Header
Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...

Request Fields 說明

欄位型別必填說明
query string ✅ 使用者問題文字
candidate_ids integer[] ✅ 選取的候選人 ID 陣列
candidates_info object[] ✅ 候選人完整資訊（含 latest_assessment）
trait_reports object ❌ 以 candidate_id 為 key 的特質報告，提供後才會扣除配額
session_id string ❌ 對話 Session UUID；若未提供則自動建立新 Session
user_id string ✅ 使用者 email，用於 Session 歸屬
mode string ❌ auto | expert | explanation；快速問題使用 expert
module_id string | null ❌ 快速問題模組 ID（如 recruit_interview），自由問答時為 null

SSE 事件流（Response: text/event-stream）

格式統一： 所有 SSE 事件均為合法 JSON（包括結束信號），前端統一用 JSON.parse() 解析，無需特殊字串比對。
text/event-stream — 正常流程
data: {"type": "meta", "intent": "recruit_interview"}

data: {"type": "token", "content": "根"}
data: {"type": "token", "content": "據"}
data: {"type": "token", "content": "報"}
data: {"type": "token", "content": "告"}
...

data: {"type": "message_id", "id": 12345}

data: {"type": "quota", "quota_summary": {"total": 100, "used": 46, "remaining": 54}}

data: {"type": "done"}
text/event-stream — 發生錯誤（串流中）
data: {"type": "token", "content": "根據報告"}
...
data: {"type": "error", "code": "STREAM_INTERRUPTED", "message": "串流中斷，請重試"}

data: {"type": "done"}
事件 type欄位說明
metaintent首個事件，回傳意圖識別結果（use case ID）
tokencontent逐 token 串流的文字內容，拼接後為完整回應
message_idid本次訊息儲存至資料庫後的主鍵 ID（用於評分）
quotaquota_summary扣除配額後的最新配額摘要
errorcode, message串流中發生的錯誤（見下方 error code 表），此後仍會發送 done
done—串流正常結束信號（JSON 格式，取代舊版 [DONE] 字串）

SSE error code 對照

code說明
DB_UNAVAILABLE資料庫在串流開始前即不可用
SYSTEM_ERRORLLM 呼叫或其他未預期例外
STREAM_INTERRUPTED串流進行中途中斷（已有部分 token 送出）

錯誤回應（HTTP 層，非 SSE 串流中）

application/json — 400
{
  "success": false,
  "data": null,
  "error": { "code": "MISSING_FIELD", "message": "query is required", "field": "query" },
  "meta": null
}
注意： 串流途中發生的錯誤不會中斷 HTTP 連線，而是透過 {"type":"error"} SSE 事件傳遞。HTTP 400/500 只在串流開始前（請求驗證階段）回傳。

行為備註

配額扣除： 僅在 trait_reports 有值時才扣除配額，並即時透過 quota 事件同步到前端。
Session 標題： 新 Session 建立後，後端會非同步觸發標題生成，無需前端介入。

HTTP 錯誤代碼對照

HTTP 狀態碼

狀態碼說明常見原因
200 成功 —
201 建立成功 POST 建立資源（如新增管理者）
400 Bad Request 必填欄位缺漏、JSON 格式錯誤、業務邏輯驗證失敗
401 Unauthorized JWT Token 遺失、格式錯誤或已過期；帳密錯誤
404 Not Found 候選人、Session 或訊息不存在
500 Internal Server Error 未預期例外，traceback 已印至伺服器 log
503 Service Unavailable 資料庫連線失敗；上游 Traitty API 不可用；LLM API 不可用

SSE 串流接收範例（JavaScript）

JavaScript
const response = await fetch(`${apiBaseUrl.replace('/api/v2', '')}/chat/`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${token}`
  },
  body: JSON.stringify({ query, candidate_ids, candidates_info, trait_reports, session_id, user_id })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
let buffer = "";

while (true) {
  const { done, value } = await reader.read();
  if (done) break;                     // 連線中斷（非正常結束）

  buffer += decoder.decode(value, { stream: true });
  const lines = buffer.split("\n");
  buffer = lines.pop();                // 保留未完成行

  for (const line of lines) {
    if (!line.startsWith("data: ")) continue;
    const raw = line.slice(6).trim();

    // 所有事件均為合法 JSON，統一解析（無需特殊字串比對）
    let event;
    try { event = JSON.parse(raw); } catch { continue; }

    if (event.type === "done")       break;        // 串流正常結束
    if (event.type === "token")      appendToken(event.content);
    if (event.type === "meta")       setIntent(event.intent);
    if (event.type === "message_id") saveMessageId(event.id);
    if (event.type === "quota")      updateQuota(event.quota_summary);
    if (event.type === "error")      showError(`⚠️ ${event.message}`);  // code: event.code
  }
}
