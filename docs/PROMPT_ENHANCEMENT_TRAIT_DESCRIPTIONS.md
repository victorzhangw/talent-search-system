# Prompt 增強：特質說明整合

## 更新日期

2025-12-18

## 更新目的

將 `trait` 表中的特質說明（description）整合到 Prompt 中，讓 LLM 能夠：

1. 準確理解每個特質的定義和衡量標準
2. 基於特質說明進行更精準的行為預測
3. 提供更具深度和專業性的分析建議

## 主要更新

### 1. 強調特質說明的重要性

在 System Prompt 中添加了明確的提示：

```
📌 重要提示：每個特質都附有詳細的「說明」欄位，這些說明定義了該特質的具體含義和衡量標準。
請務必仔細閱讀並理解這些定義，它們是準確解讀候選人行為模式的關鍵依據。
```

### 2. 完整特質列表說明

```
📋 完整特質列表（含定義說明）
請特別注意：每個特質後方的「說明」欄位清楚定義了該特質的衡量維度。在分析時，請：
1. 依據說明理解特質的真實含義
2. 結合分數判斷該特質的強弱程度
3. 思考該特質在職位中的重要性
4. 分析特質間的交互作用和組合效應
```

### 3. 新增分析維度

添加了「特質組合」分析維度：

```
5. 特質組合：觀察多個特質的組合效應
   例如：高成就追求 + 低韌性 = 容易因挫折而放棄
```

### 4. 更新推理準則

```
- 定義為本：解讀特質時，必須以特質說明中的定義為準，不可憑主觀臆測
- 證據導向：所有推論必須明確引用對應的特質分數和說明作為支撐依據
```

### 5. User Prompt 要求更新

```
1. 嚴格依據特質說明：每個特質的解讀必須基於其說明欄位中的定義
2. 數據支撐：所有行為預測都要引用具體的特質分數和說明
```

## 特質資料格式

每個特質現在包含完整的說明：

```
1. 成就追求     (Achievement Motivation):  89.0 分
   說明: 衡量一個人對待工作認真的程度、提高工作表現的意願，以及努力達成目標的程度。

2. 韌性         (Resilience):  81.0 分
   說明: 衡量一個人面對挫折和壓力時的恢復能力和適應變化的能力。
```

## 預期效果

### 更精準的分析

**之前**（沒有說明）：

```
候選人的 Achievement Motivation 分數很高（89分），表示他很有上進心。
```

**現在**（有說明）：

```
候選人的「成就追求」分數高達 89 分，根據特質定義，這表示他對待工作極為認真，
具有強烈的提高工作表現意願，並會努力達成設定的目標。在職場中，這意味著他會：
1. 主動設定挑戰性目標
2. 持續追求卓越表現
3. 對工作成果有高標準要求
```

### 更深入的組合分析

```
候選人的「成就追求」（89分）和「韌性」（81分）都很高，這是一個強大的組合：
- 高成就追求驅動他設定高目標
- 高韌性確保他在遇到挫折時不會輕易放棄
- 這種組合特別適合需要長期努力和克服困難的專案型工作
```

### 更具體的建議

```
雖然候選人的「決策能力」（48分）較低，但根據特質說明，這主要衡量在複雜情境下
快速做出判斷的能力。建議：
1. 在初期提供更多的決策框架和指引
2. 安排經驗豐富的導師協助重大決策
3. 透過案例學習逐步提升決策信心
```

## 技術實現

### 資料流程

1. 從 `trait` 表載入特質映射（`_get_trait_name_mapping()`）
2. 從 `test_project_result.trait_results` 獲取分數
3. 合併資料，生成包含說明的完整特質資訊
4. 格式化後傳入 Prompt
5. LLM 基於完整資訊生成分析

### 程式碼位置

- Prompt 模板：`BackEnd/prompts/hr_consultation_prompts.json`
- 資料處理：`BackEnd/hr_consultation_service.py`
  - `_get_trait_name_mapping()` - 載入特質映射
  - `_analyze_strengths_weaknesses()` - 分析優劣勢
  - `_build_hr_system_prompt()` - 構建 Prompt

## 範例對比

### 問題：「這位候選人適合擔任專案經理嗎？」

**之前的回答**：

```
候選人的領導力和溝通能力都不錯，應該可以勝任專案經理。
```

**現在的回答**：

```
基於測評數據分析，候選人具備專案經理的部分核心能力：

優勢方面：
- 「成就追求」89分：根據定義，這表示他對工作極為認真，會努力達成專案目標
- 「韌性」81分：面對專案中的挫折和壓力時，具備良好的恢復能力

需要關注的方面：
- 「決策能力」48分：在複雜情境下快速做出判斷的能力較弱，建議在初期提供決策框架
- 「系統思考」48分：整體把握專案全局的能力需要加強，建議搭配經驗豐富的副手

建議：適合擔任中小型專案的經理，或在大型專案中擔任執行層面的角色。
```
