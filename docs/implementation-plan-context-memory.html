關鍵細節：排除當前訊息

ℹ️
routes/chat.py:291 在呼叫 generate_response 之前已執行
session_store.add_message(session_id, 'user', query)

因此從 DB 取出的歷史中，最後一條就是當前 query。必須排除，否則 LLM 會收到兩次相同的問題。

程式碼：修改前

        {"role": "system", "content": sys_prompt.strip()},

程式碼：修改後

python 新增內容 
def _call_llm(self, sys_prompt, query, uc_id, session_id="unknown"):
    self._log_prompt(session_id, uc_id, sys_prompt, query)

    # ── 載入對話歷史 ──────────────────────────────────────────
    history_messages = []
    if session_id and session_id != "unknown":
        try:
            from .session_store import SqlSessionStore
            max_turns = current_app.config.get('MAX_HISTORY_TURNS', 6)
            db_msgs = SqlSessionStore().get_messages(session_id)
            # 只保留 user / assistant，排除 system 背景訊息
            conv = [m for m in db_msgs if m.role in ('user', 'assistant')]
            # 最後一條是剛存入的當前 query，排除避免重複
            if conv and conv[-1].role == 'user':
                conv = conv[:-1]
            # 取最近 max_turns 輪（1 輪 = user + assistant 共 2 條）
            conv = conv[-(max_turns * 2):]
            history_messages = [
                {"role": m.role, "content": m.content}
                for m in conv
            ]
            rag_logger.info(f"[History] Loaded {len(history_messages)} msgs for session {session_id}")
        except Exception as e:
            rag_logger.warning(f"[History] Failed to load history: {e}")
    # ──────────────────────────────────────────────────────────

    messages = [
        {"role": "system", "content": sys_prompt.strip()},
        *history_messages,  # 插入歷史輪次
        {"role": "user",   "content": query}
    ]

已知限制與後續規劃

V1 已知限制

  • 恢復歷史後，新問題不帶候選人特質資料。
    恢復後 activeConversationCandidateIds 為空，LLM 只有對話歷史可參考，無法執行新的特質深度分析。使用者若需分析新問題，須重新選取候選人。
  • context 上限為輪數而非 token 數。
    極端長回應（如 2,000 字回答）6 輪可能消耗較多 token，但仍在安全範圍內（<15K tokens）。

V2 後續規劃（非本次範圍）

  • 在 switchContextToPreview 中，從 session metadata_.candidates 恢復 candidate IDs，並自動重新 fetch trait reports，讓恢復後的對話能繼續進行特質分析。
  • 新增動態 token 計算，當歷史訊息超過閾值時自動截斷最舊輪次（而非固定輪數）。
