## 更新概述

重新設計並統一了專案的啟動腳本，提供更簡單、更可靠的啟動方式。

## 更新內容

### 1. 刪除舊腳本

**根目錄刪除的腳本**：

- `cleanup-unnecessary-files.bat`
- `push-all.bat`
- `RESTART_BACKEND_NOW.bat`
- `start-all-services.bat`
- `start-all.bat`
- `start-backend.bat`
- `start-frontend.bat`
- `START-HR-CONSULTATION.bat`
- `START.bat`
- `stop-all-services.bat`
- `stop-all.bat`
- `venv-start-all.bat`

**BackEnd 目錄刪除的腳本**：

- `start-hr-api.bat`
- `start-local.bat`

**刪除原因**：

- 腳本過多，功能重複
- 命名不統一
- 缺乏維護
- 使用體驗不佳

### 2. 新增統一腳本

#### Windows 腳本

**start.bat** - 統一啟動腳本

- 自動檢查環境（Python、Node.js）
- 自動檢查配置文件（.env.local）
- 自動創建虛擬環境（如果不存在）
- 自動安裝依賴（如果不存在）
- 啟動後端服務（新窗口）
- 啟動前端服務（新窗口）
- 自動打開瀏覽器
- 顯示訪問地址和使用提示

**stop.bat** - 統一停止腳本

- 通過端口查找並終止後端進程（8000）
- 通過端口查找並終止前端進程（5173）
- 關閉相關命令窗口
- 清理進程

**check-environment.bat** - 環境檢查腳本

- 檢查 Python 版本
- 檢查 Node.js 版本
- 檢查環境變數文件
- 檢查虛擬環境
- 檢查前端依賴
- 檢查配置文件
- 顯示檢查結果和修復建議

#### Linux/Mac 腳本

**start.sh** - 統一啟動腳本

- 自動檢查環境
- 自動創建虛擬環境
- 自動安裝依賴
- 後台啟動後端服務
- 後台啟動前端服務
- 保存進程 ID 到文件
- 記錄日誌到文件
- 在 Mac 上自動打開瀏覽器

**stop.sh** - 統一停止腳本

- 讀取 PID 文件終止進程
- 或通過端口查找並終止進程
- 清理 PID 文件
